# Biomedical Image Analysis

**Biomedical Imaging Laboratory | Politecnico di Milano**

## Overview

This repository contains a collection of laboratory assignments developed as part of my studies in Information Bioengineering at Politecnico di Milano.

The projects explore biomedical image processing and analysis, combining classical image processing techniques, computational methods, and machine learning to address practical imaging problems.

## Topics & Applications

The assignments cover several aspects of biomedical image analysis:

- **Image Enhancement & Frequency Analysis:** Contrast enhancement, histogram transformations, 2D Fourier analysis, and frequency-domain processing.
- **Filtering & Noise Analysis:** Spatial filtering, noise characterization, and frequency-selective noise removal.
- **Image Segmentation:** Edge detection, morphological operations, region-based analysis, and anatomical structure extraction.
- **Medical Image Analysis:** Segmentation of thoracic and cardiac structures from volumetric and time-resolved MRI data.
- **Machine Learning for Medical Imaging:** Feature extraction using Histogram of Oriented Gradients (HOG), classification algorithms, and model evaluation applied to fetal ultrasound images.
